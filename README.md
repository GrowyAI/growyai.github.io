# 🌱 Growy

> **用科学与 AI 辅助你的育儿之路 —— 你陪孩子共同成长，我们陪你同行。**

Growy 是一套开放的育儿辅助工具集，帮助父母在信息爆炸的时代，把精力真正花在“最重要的事”上。  
目前包含时间线探索、益智游戏、AI 育儿咨询、优先级规划等多个轻量工具，所有内容均可从统一首页直达。

## 🚀 快速开始

本项目为纯静态前端页面，无需安装依赖或构建。

1. 克隆仓库  
   ```bash
   git clone https://github.com/GrowyAI/growy.git
   ```

2. 用任意现代浏览器直接打开 index.html 即可。

如果只想在线体验，无需下载，直接访问首页对应的 GitHub Pages 或本地启动静态服务器均可。

🛠️ 技术栈

· HTML5 / CSS3
· 原生 JavaScript
· 每个页面均可独立运行，轻量、快速。
