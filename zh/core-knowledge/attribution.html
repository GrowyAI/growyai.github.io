2. 本工具做了哪些修改

  • 将 PDF 中的知识点重新解析、结构化，按学前 / K–8、年级、学科、主题、子主题与类型整理。
  • 为全部条目添加中文翻译，并保留英文原文与来源页码。
  • 增加学科 / 主题 / 类型筛选、搜索、收藏和大纲导航。
  • 导出 JSON / CSV / XLSX 数据，并用少量具体名词或动作 emoji 作为视觉提示。
  • 为条目中提到的具体作品或名称添加 Google 搜索链接，方便查找介绍与适龄资源。

因此，本工具中的结构化数据、中文翻译与页面呈现属于对上述原始材料的改编作品，同样按 CC BY-NC-SA 4.0 分享。

4. 关于图片、emoji 与外部链接

公开版本不包含从原 PDF 提取的图片。条目中的 emoji 是 Unicode 字符，仅作提示；另有 272 条知识点配有来自 Wikimedia Commons 的图片，只选用明确标注为 Public Domain 或 CC0 的文件，并已人工核对。

图片以热链加载，不复制到本站；点击可全屏查看，图下注明文件、作者与许可。来源链接失效时会自动隐藏并提示前往 Commons 查看，原图版权状态以 Commons 页面为准。

部分条目中的「相关资料 ↗」是自动生成的 Google 搜索链接，仅用于查找介绍；本站不托管也不背书搜索结果内容，其版权归原权利方所有。
