# 数据包说明

本目录放数据；界面在上层 `index.html`，顶部一行年龄/年级按钮直接列出幼儿园年龄段与小学初中年级段（界面显示 `3-4岁` / `4-5岁` / `5-6岁` / `1-2年级` / `3-4年级` / `5-6年级` / `7-9年级`，URL 仍沿用原 key）：

1. **幼儿园阶段**：教育部 2012 年《3-6岁儿童学习与发展指南》，按小班 / 中班 / 大班组织。
2. **小学与初中阶段**：教育部 2022 年版 16 份课程标准（语文、数学、英语、道德与法治、历史、地理、科学、物理、化学、生物学、信息科技、体育与健康、艺术、劳动、日语、俄语），按学段组织。

官方 PDF / DOC 和 OCR / 抽取出的中间文本都在被 gitignore 的 `../source/` 下，不进入公开仓库。

## 「干货」筛选

小学初中数据经过 `concrete-v1` 筛选，页面只展示能给家长具体信息的条目：带数字、有可观察动作，且动作落在具体对象上。概念定义、政策口号、「要引导学生……」这类教学口吻，以及 OCR 表格碎片会被筛掉。

被筛掉的条目**暂存但不展示**在对应的 `*-excluded.json` / `.csv` 中，每条带 `filter_reason`。它们没有删除；如需恢复，调整构建脚本里的筛选规则后重新构建即可。幼儿园发展目标全部保留，教育建议带具体举例或给出具体行动时保留，其余 5 条暂存。

## 文件

### 幼儿园

- `preschool.json`：canonical 数据，含 `meta` 与 `items`。
- `preschool-inline.js`：静态页面直接加载的 `window.PRESCHOOL_DATA`。
- `preschool.csv` / `preschool.xlsx`：表格版。
- `preschool-preview.md`：按领域 → 方面 → 目标排版的可读预览。
- `preschool-excluded.json` / `preschool-excluded.csv`：未展示教育建议的暂存档案。

由 `../scripts/build_preschool_data.py` 从本地 `.doc` 抽取文本生成。

### 小学与初中（16 科）

- `primary-secondary.json`：16 科合并的 canonical 数据，含 `meta` 与 `items`。
- 按科目拆出的同名 JSON：`chinese` / `math` / `english` / `politics` / `history` / `geography` / `science` / `physics` / `chemistry` / `biology` / `information` / `pe` / `arts` / `labor` / `japanese` / `russian`。
- `primary-secondary-inline.js`：静态页面可加载的 `window.PRIMARY_SECONDARY_DATA`。
- `primary-secondary.csv` / `primary-secondary.xlsx`：表格版。
- `primary-secondary-preview.md`：按科目 → 学段 → 领域 → 主题排版的可读预览。
- `primary-secondary-excluded.json` / `primary-secondary-excluded.csv`：未展示条目的暂存档案，带筛选原因。

由 `../scripts/build_subjects_data.py` 从本地 OCR 文本生成。16 份标准都是扫描图片 PDF、没有文字层，因此需先用 `../scripts/ocr_pdfs.py <key> --pages <范围>` 生成文本；OCR 结果缓存在 `../source/extracted/ocr/`，不会进仓库。语文 / 数学 / 英语用专用解析器，其余 13 科使用基于标题、学段与编号的通用解析器。

## 界面接入

`index.html` 同时加载上面两个 inline JS，顶部只有一行年级按钮（与英文版一致），不再分数据集 tab，也没有「全部 / 全学段」选项：

- 幼儿园年级：`小班` / `中班` / `大班`，分类下拉为 `domain` / `aspect` / `goal` / `type`。
- 小学初中年级：`x1` 小学低段 / `x2` 小学中段 / `x3` 小学高段 / `j1` 初中，分类下拉为 `subject` / `domain` / `topic` / `type`。

所有筛选共用一个 URL 参数 `grade`：幼儿园用 `小班` / `中班` / `大班`（URL 中会被编码），小学初中用 `x1` / `x2` / `x3` / `j1`；另有 `subject` / `domain` / `aspect` / `goal` / `topic` / `type` / `q`。切换年级会清空其他筛选。旧的 `?view=preschool&stage=...` 链接仍可打开，会自动改写成 `?grade=...`。

分类下拉随年级变化：选幼儿园年级显示领域 / 方面 / 目标，选小学初中年级显示科目 / 领域 / 主题。搜索框、收藏与长条目折叠共用；收藏存在浏览器 `localStorage` 的 `cn-curriculum-favs`，`uid` 前缀不同，不会互相覆盖。幼儿园选中年龄段后仍显示通用教育建议；小学初中选中年级后仍显示「全学段通用」条目，因此去掉该筛选项不会丢失内容。

起始年级按《义务教育课程方案（2022年版）》处理：历史、地理、物理、化学、生物学、日语、俄语只在初中显示（俄语与日语是初中可选外语语种）；英语 1-2 年级条目来自课标预备级，对应「有条件的地区和学校可在一至二年级开设，以听说为主」；信息科技 1-2 年级内容在课标中列入第一学段，但按课程方案 3-8 年级才单独开设，其他年级相关内容融入语文、道德与法治、科学、劳动等课程，这里仍按课标学段保留。

## 数据规模

### 幼儿园

- 5 个领域、11 个方面、32 个目标。
- 316 条发展水平条目：小班 94 / 中班 105 / 大班 117。
- 104 组教育建议展示，其中 59 组带 `examples` 举例；另 5 组笼统建议暂存不展示。
- 共 420 条展示 item，`uid` 唯一。

### 小学与初中

OCR 后共抽取 **4147 条**，另从官方课标附录整理 **162 条**具体清单，经 `concrete-v1` 筛选后**展示 1915 条**，暂存 2460 条。展示条目的 `uid` 全部唯一，`text` 无空值，`source_page` 齐全；暂存与展示条目没有 UID 重叠。

暂存原因以 `filter_reason` 记录：`no-concrete`（缺少可观察的具体内容）、`meta`（概念定义或教学口吻）、`type-noncontent`（教学提示类）、`garbled-*`（OCR 表格碎片或重复断行）等。筛选是启发式的，宁可暂存的略多；如发现误筛，可在暂存档案中查找并调整规则。

道德与法治、科学、物理、化学、生物学的核心内容在原件里是双栏表格，OCR 会把左右两栏文字交错读出。体育与健康、艺术、劳动、日语、俄语含较多表格与跨页段落，少量已展示条目仍可能有文字断行或层级偏粗，使用时请以原文为准。

学段键 `stage_key`：`x1` 小学低段（1–2 年级）、`x2` 小学中段、`x3` 小学高段、`j1` 初中、`p` 小学 1–6 年级（仅在三个小学年级出现）、`all` 全学段通用（界面不再提供单独的「全学段」筛选，筛选后这 111 条会出现在每个年级里）。原先标成 `all`、但正文实际按「1–2 年级 / 3–4 年级 / …」分段列出的 55 条，已按学段手动拆分；含 ① 等内部编号的长条目保持一条，但会在正文中插入换行。英语标准中的「预备级（1–2 年级）」已并入 `x1`，相关领域名称也统一显示为「小学低段学习活动」。

### 课标附录（本轮新增）

参考文献集中在教育部 2022 年版课标官方 PDF，不引入第三方清单作为展示来源。语文课标附录整理出 162 条：

- 附录1 优秀诗文背诵推荐篇目 135 篇（段）：1–6 年级 75 篇、7–9 年级 60 篇（段）；这是**推荐篇目**，不是全国统一必考清单。
- 附录4 识字、写字教学基本字表 300 字，按 1–13 画分成 13 组，作为第一学段识字写字教学的重要内容。
- 附录5 常用字表 3500 字的构成说明（字表一 2500 字 / 字表二 1000 字）。扫描表格无法可靠逐字识别，因此不发布自动 OCR 的字表，完整字表请以官方 PDF 附录5 为准。
- 附录2 课内外读物建议 6 组、附录3 语法修辞知识 6 组。

这 162 条 `type` 为 `appendix`，`domain` 为「课标附录」，在界面「类型」下拉里可单独筛选。其它学科（英语词汇表、日语/俄语词汇与交际用语、科学和化学的必做活动）仍在官方附录中，后续可按同样方式补入。

## 字段说明

### 幼儿园 item

| 字段 | 含义 |
| --- | --- |
| `uid` | 稳定标识，如 `ps-h-a1-g1-x-01` |
| `domain` / `aspect` | 领域 / 方面 |
| `goal_no` / `goal` | 目标序号 / 目标标题 |
| `type` | `goal` 或 `suggestion` |
| `text` | 发展水平条目或教育建议正文 |
| `examples` | 教育建议中的举例（仅 `suggestion` 可能有） |
| `reference` | 身高体重参考标准（仅健康领域目标 1 的发展水平条目） |
| `stage` / `age` | 发展水平条目所属年龄段（`suggestion` 无此字段） |
| `source_page` | 所属“方面”在指南印刷版中的起始页 |
| `source_id` | 指向 `meta.source` |

### 小学与初中 item

| 字段 | 含义 |
| --- | --- |
| `uid` | 稳定标识，如 `ch-x1-sta-xxxxxxxx` / `ma-j1-con-xxxxxxxx` / `en-x2-con-xxxxxxxx` |
| `seq` | 构建时的顺序号 |
| `subject` / `subject_key` | 科目中文名 / 键（`chinese` / `math` / `english`） |
| `stage` / `stage_key` | 学段中文名 / 稳定键 |
| `domain` | 领域或课程要素，如「数与代数」「语言知识」「阅读与鉴赏」 |
| `topic` | 子主题或要求类别，如「数与运算」「语音知识」「教学提示」 |
| `type` | `stage_requirement` / `content` / `academic` / `tip` / `theme` / `note` / `appendix` |
| `text` | 抽出的条目正文 |
| `source_page` | 印刷版起始页 |
| `source_pdf_page` | 对应 PDF 物理页 |
| `source_id` | 指向 `meta.sources` 中的一份标准 |
