2. What this tool changes

  • Re-parses and structures the PDFs into Preschool / K–8, grade, subject, topic, subtopic, and type.
  • The source dataset includes Chinese translations; this English view shows English text only.
  • Adds subject / topic / type filters, search, saved items, and an outline navigator.
  • Exports JSON / CSV / XLSX data and uses a small number of concrete noun or action emoji as visual cues.
  • Adds Google search links for named works so readers can find introductions and age-appropriate resources.

The structured data and page presentation in this tool are therefore an adaptation of the source material and are shared under CC BY-NC-SA 4.0 as well.

4. Images, emoji, and external links

The public version does not include images extracted from the original PDFs. Emoji in items are Unicode characters used only as cues; 272 items have images from Wikimedia Commons, limited to files explicitly marked Public Domain or CC0 and checked manually.

Images are hot-linked, not copied into this site. Click one to view it full-screen; the file, artist, and license are shown below it. If a source link stops working, the image is hidden and a link to Commons is shown. Copyright status follows the Commons page.

Some items include an auto-generated "Related resources ↗" Google search link, useful only for finding introductions. This site does not host or endorse search results, whose copyright belongs to their respective owners.
